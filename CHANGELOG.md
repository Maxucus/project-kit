# Changelog

## 0.1.0 — preview

- Компактный контекст, три собственных lifecycle skills, шаблоны требований и решений.
- Superpowers 6.4.2 и ECC 2.2.2 закреплены submodules по commit; внешние пакеты не изменены.
- CLI `init`, `check`, `upgrade`: проверка содержимого, сохранение проектных файлов, возобновление и отдельный worktree.
- Проектные адаптеры Codex/Claude Code и строгая проверка runtime без ложного `ready`.
- Сценарии CSV CLI и HTTP API; живые ограничения — в [совместимости](docs/compatibility.md).

Полная runtime-приёмка профиля ещё не подтверждена; номер пакета не означает готовность релиза v1.
