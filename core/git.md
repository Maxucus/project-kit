# Git

Поддерживай рабочую main и короткие ветки задач. Изменения оформляй через PR с
проблемой, новым поведением и проверками. Коммиты объединяют связанную работу.
Worktree используй для параллельных задач; не переключай чужой checkout.

Перед записью проверь статус и область изменений. Сохраняй чужие правки;
не делай reset, force-push, stash или удаление веток без соответствующего намерения пользователя.
Обновляй зависимости явно, с проверкой diff и совместимости. Версия Project Kit
закрепляется commit; upstream pins принадлежат самому набору.

Merge, публикация и развёртывание — отдельные операции; выполняй их в пределах
согласованной задачи. Секреты, локальные кеши и данные авторизации в Git не попадают.
