# Процесс

- Исследование: вопрос → ограниченный эксперимент → вывод с основаниями.
- Небольшое изменение: ожидаемый результат → решение → реализация → проверка.
- Новая подсистема: требования → варианты → согласованный дизайн → план → реализация → проверка.

Масштаб выбирается по неопределённости и цене ошибки. Профиль назначает основной skill
этапа; выполняй его обязательные условия, не запускай конкурирующие workflows одновременно.
Существенное решение фиксируй в ADR: контекст, варианты, выбор, причины, последствия.
Стек следует из требований, эксплуатации и компетенций, а не из любимого шаблона.

У задачи один источник, указанный в docs/development.md; там сохраняй приёмку и состояние.
Чат и локальный план не создают второй backlog. При смене агента передай цель,
решения, ссылки на изменения, проверки и оставшуюся работу.
