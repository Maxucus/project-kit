# Приёмочные сценарии

## CSV CLI

Пользователь: аналитик. Цель: посчитать строки данных CSV без заголовка.
Граница: один локальный файл; сеть и база данных не нужны.
Ограничения: UTF-8, стандартная библиотека Python, пути с пробелами.
Решение: Python CLI; библиотека csv корректно обрабатывает кавычки и переносы.
Приёмка: для заголовка и двух записей stdout равен `2`; неверный путь даёт ненулевой exit.
Проверка: `python app.py input.csv`. Источник задач: GitHub Issues проекта.

## HTTP API

Пользователь: оператор. Цель: проверять доступность сервиса через `GET /health`.
Граница: один HTTP endpoint; аутентификация и хранение данных вне задачи.
Ограничения: Node.js 22+, стандартная библиотека, JSON, локальный временный порт в тесте.
Решение: node:http; фреймворк пока не даёт необходимой функции.
Приёмка: HTTP 200 и `{"status":"ok"}`; неизвестный маршрут даёт 404.
Проверка: `node server.mjs` и HTTP-запрос. Источник задач: GitHub Issues проекта.

Для обоих сценариев: документы сохраняют каждый пункт brief; оба агента находят общие
правила и закреплённые skills. Повторная настройка не меняет проект. После локальных
правок README и ADR обновление набора сохраняет их. Конфликт управляемого файла
обнаруживается; разные версии двух проектов не подменяют друг друга.

Автономные тесты используют небольшие локальные пакеты и нативный инвентарь как
контролируемую внешнюю границу. Живая совместимость подтверждается отдельно.
