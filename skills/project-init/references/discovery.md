# Входные решения

Сначала используй уже известное. Задавай один вопрос, который снимает наибольшую неопределённость.

| Поле intent | Решение |
| --- | --- |
| name, goal | Что создаём и зачем |
| users | Кто выполняет основной сценарий |
| scope | Что входит и не входит в первую поставку |
| constraints | Среда, данные, интеграции, бюджет, сроки, эксплуатация |
| decisions | Принятый выбор с альтернативами, причиной и последствиями |
| success | Наблюдаемые критерии приёмки |
| task_source | Единственный источник задач |
| commands | Команды разработки и проверки как массивы аргументов |
| generation | Согласованные команды scaffold; версии генераторов закреплены |

Отделяй требование от предположения. Неизвестное, влияющее на архитектуру, выясни до генерации.
В YAML поля обязательны; generation может быть пустым для уже подготовленного scaffold.
