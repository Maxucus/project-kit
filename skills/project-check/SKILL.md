# Проверить проект

Вход: корень проекта и требуемая область проверки.

Запусти `project-kit check --project PATH`; для фактической конфигурации клиента
добавь `--runtime`. Прочитай диагностику, сверив intent с проектными документами:
цель, границы, ограничения, решения, критерии результата и ссылки должны сохраниться.
Проверка не исправляет проект автоматически.

Результат: статус каждого условия, общий статус и конкретные оставшиеся действия.
Приоритет: incompatible → drift → incomplete → ready. Пропущенная обязательная
runtime-проверка остаётся incomplete. Не приравнивай номер версии, наличие manifest
или ответ модели к доказательству фактически загруженного пакета.

Заверши кратким отчётом о проверенном и непроверенном; исправления выполняй отдельным
согласованным изменением по workflow проекта.
