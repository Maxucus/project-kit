# Project Kit

Цель: компактная версионируемая методология, skills и scaffold для Codex и Claude Code.
Краткость сохраняет цель, границы, ограничения, решения и критерии результата.

Начни с [README](README.md). Для изменения поведения прочитай
[дизайн](docs/superpowers/specs/2026-10-01-project-kit-design.md) и относящуюся
к задаче часть [плана](docs/superpowers/plans/2026-10-01-project-kit.md).

Работай в ветке задачи, сохраняй чужие изменения. Проверяй наблюдаемое поведение;
не объявляй готовность по наличию файлов. Upstream не редактируется: меняй закрепление
или адаптер. Код, документация и подтверждённая совместимость должны совпадать.
Не выводи секреты. Источник задач — GitHub Issues/PR этого репозитория.
