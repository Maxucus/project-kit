# Project Kit

Версионируемая методология, skills и scaffold для запуска и ведения проектов через Codex и Claude Code.

- Требования определяют стек и техническую основу.
- Общие правила компактны; подробный контекст открывается по задаче.
- Внешние наборы закреплены по commit, собственные skills развиваются отдельно.
- Обновления сохраняют код, решения и настройки проекта.

Реализация v1 ведётся в ветке задачи. Вход для агентов — [AGENTS.md](AGENTS.md);
переносимые правила — [core](core/entry.md), собственные workflows — [skills](skills/).

[Спецификация](docs/superpowers/specs/2026-10-01-project-kit-design.md) содержит архитектуру, структуры файлов и критерии готовности.

[План реализации](docs/superpowers/plans/2026-10-01-project-kit.md) разбивает работу на семь проверяемых задач.
