# Codex

Каталог проекта ссылается на неизменяемые локальные пакеты; .codex/config.toml
управляет активностью только в доверенном проекте. Настройки пользователя не меняются.
Совпадающие пакеты из других marketplaces отключаются проектным override.

Проверка читает `codex plugin list --json`, затем skills/hooks через app-server stdio.
Сравниваются реальные пути и содержимое установленного пакета. Вызов модели не нужен.
Если проект ещё не доверен или hooks не приняты, заверши штатные действия в Codex
и повтори `project-kit init --project PATH`. Доверие автоматически не назначается.
Чужой каталог marketplace сохраняется; конфликт его имени требует явного разбора.

[Нативная конфигурация](https://developers.openai.com/plugins/build/plugins#enable-or-disable-a-plugin-for-a-repo).
